# thesis-baselines

Answering baselines for [thesis-research-agent](https://github.com/guptaaditya746/thesis-research-agent)
(PaperQA2, long context, plain RAG). Each one answers the same questions from the same papers with the same
model, and writes JSON that `evqa` scores and `evqa compare` puts next to the main system.

Used as a git submodule at `baselines/` in thesis-research-agent (like `llm-setup/`).
